This fork no longer exports the copied `dsh-agent-teams-doctor` executable.

The configured Web profile contains Plugin Market `dshmarket@1.66.17`, original AgentTeams `0.1.23`, BrowserSkill DSH plugin `0.3.2`, and this locally linked package. Model proxy settings were preserved. Plugin Market was installed first; BrowserSkill was installed through its catalog and showed Enabled alongside original AgentTeams.

Its current delivery guide makes GitHub the tracker, so the panel automatically selects `Ihab-Zhaika/TrucX`, remote `github`, default branch `main`, M0–M9 in plan order, and `pwsh -NoProfile -File scripts/ci-local.ps1`. The BrowserSkill executable `0.3.2` was installed from Tencent's release with verified SHA-256, and its absolute path is configured in the profile. No separate BrowserSkill skill installation is needed for DSH.

A real DSH host probe in TrucX confirmed original team captain tools and `darkingdoom_status` coexist, the old custom status tool is absent, and an independent worker receives `danger-full-access` with approval `never`. All 115 focused tests pass. The launcher and installed plugin entry names are separate from original AgentTeams. Open the Web GUI, select TrucX, create or open its main chat and use **DarKingDoom Plugin** in the right sidebar's **Start** menu or the session header. The native tab keeps the chat visible and usable; switch between **Configuration** and **Monitor** inside it. Draft settings stay mounted while the sidebar is hidden or another session/tab is selected. Repository settings load automatically. For a bounded trial set **Ticket limit** as well as parallelism: parallelism limits simultaneous work, while a ticket limit counts admissions over the whole run, including recovery and failed setup. Zero means continuous intake. Adjust scope if needed, enable optional memory/browser requirements only when connected, then explicitly start the run. Future ordinary chats do not acquire orchestration authority automatically.
